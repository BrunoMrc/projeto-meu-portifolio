# meu-portifolio
Projeto meu Portifolio

Portfólio pessoal de desenvolvimento Front-end, com apresentação, habilidades e projetos, publicado via GitHub Pages.

🔗 **[Ver projeto ao vivo](https://brunomrc.github.io/projeto-meu-portifolio)**

💻 Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome (ícones)
- Git e GitHub

🏋️ O que pratiquei

- Estruturação de uma página única com HTML5 semântico (header, nav, main, section, footer)
- Estilização e layout responsivo com CSS3
- Navegação entre secções com âncoras
- Renderização dinâmica das habilidades e dos projetos com JavaScript
- Organização do projeto em pastas (estilos, scripts, imagens)
- Versionamento com Git e publicação com GitHub Pages
